# Web blocking data and notices

This directory contains the filter snapshot used by Noteboard+. The original
downloaded lists and resource data are included in `sources/`. Their individual
notices remain intact. `manifest.json` records the source URLs, SHA-256 digests,
download date and engine version. No warranties are provided by these projects.

  Origin contributors, under GPL 3.0. Sources:
  https://github.com/uBlockOrigin/uAssets and https://github.com/gorhill/uBlock .
  Ghostery's compatible resource snapshot is distributed at the exact URL in
  the manifest. See `GPL-3.0.txt` and retained per-list notices.
- **Peter Lowe's list** — Peter Lowe, https://pgl.yoyo.org/adservers/ . The author
  permits combining and redistributing this hostname list; source and credits
  are retained in the downloaded file.

The serialized `engine.bin` is generated by Ghostery from those sources without
editing their rules. To refresh the bundled snapshot in this project, run
`npm run filters:update`; the generator is `scripts/update-web-filters.mjs`.
The desktop app can also fetch verified updates into its own local cache.
Blocking stays available from this bundle when updates cannot be downloaded.
